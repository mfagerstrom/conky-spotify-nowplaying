# conky-spotify-nowplaying

A Spotify "now playing" desktop widget for Linux (GNOME on Wayland), built on Conky.

- Album art, title and artist, with long titles wrapped to a fixed widget width
- Spotify-style controls: previous / play-pause / next, and a seek bar you can click or drag
- Like button (♥) showing whether the track is in your Liked Songs, click to toggle
- Smoothly scrolling synced lyrics from [LRCLIB](https://lrclib.net): previous, current and next line
- Background colour taken from the album art, fading between tracks
- Drag the widget anywhere, on any monitor; its position is remembered

## How it works

| File | Role |
| --- | --- |
| `conky.conf` | Conky window setup; renders the text generated by `nowplaying.py` |
| `nowplaying.py` | Reads Spotify via `playerctl` (MPRIS), fetches art/lyrics/like state, writes the widget text plus geometry for `draw.lua` and click areas for `conky-mouse.py` |
| `draw.lua` | Cairo drawing: background, buttons, seek bar, lyric scrolling (20 fps) |
| `conky-mouse.py` | Handles clicks and dragging (Conky's own mouse hook gets no button presses under XWayland) and keeps the window at its saved position |
| `spotify_api.py` | Minimal Spotify Web API client (PKCE login, like/unlike) |
| `run.sh` | Starts everything; the Python helpers restart automatically if they exit |

Runtime state lives outside the repo: `~/.config/conky/{position,spotify-client-id,spotify-token.json}`
and `~/.cache/conky-nowplaying/`.

## Install

```sh
./install.sh
setsid ~/.config/conky/run.sh >/dev/null 2>&1 &
```

`install.sh` installs the dependencies with apt, symlinks the source files into
`~/.config/conky` (edits in this repo take effect directly) and adds a GNOME autostart entry.

### Like button (optional)

Playback control, lyrics and album art work without any account setup. For the like button:

1. Create an app at <https://developer.spotify.com/dashboard> with redirect URI
   `http://127.0.0.1:8888/callback` and the **Web API** enabled.
2. Save its Client ID: `echo YOUR_CLIENT_ID > ~/.config/conky/spotify-client-id`
3. Click the heart on the widget and approve access in the browser.

No client secret is needed (PKCE). The refresh token is stored in
`~/.config/conky/spotify-token.json` with mode 600.

## Notes

- Tested on Ubuntu 26.04, GNOME/Wayland, with 2x display scaling across three monitors.
- The widget is an unmanaged ("override") window: it stays on top on every workspace.
- Lyrics coverage depends on LRCLIB; only synced lyrics are shown.
